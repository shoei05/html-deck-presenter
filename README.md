# html-deck-presenter

学会発表や講義のスライドを、1つの HTML ファイルで作り、そのまま投影するための見本です。見本のスライドの内容（外来で説明資料を事前に渡す取り組み）と数値は、すべて架空です。発表者用の画面（P キー）が同じファイルに入っています。

デモ: https://shoei05.github.io/html-deck-presenter/

## 使い方

1. `index.html` をブラウザで開きます。
2. → / ← で進む・戻る（要素を1つずつ出します）。Shift+→ / Shift+← でスライド単位に移ります。
3. P キーで発表者用の画面が別の窓に開きます。聴衆用の画面と連動します。

| キー | 動作 |
|---|---|
| → / ← / Space / PageDown / PageUp | 次へ・前へ |
| Shift+→ / Shift+← | 次・前のスライドへ（途中の表示を飛ばす） |
| Home / End | 最初・最後のスライド |
| P | 発表者用の画面を開く |
| O / Esc | 全スライドの一覧（押すとそのスライドへ移る） |
| N | 読み原稿の表示と非表示 |
| F | 全画面 |
| R | スライドに `data-results` があれば、そのURLを開く |

## 発表者用の画面

- 今のスライド
- 次のスライド、または同じスライドで次に現れる要素
- 読み原稿（各スライドの `<aside class="notes">`）、スライドごとの目安の時間、話し始める予定の時刻
- 経過時間（押すと0に戻る）と時計
- 全スライドの縮小一覧（押すとそのスライドへ移る）
- レーザーポインター（発表者の画面でマウスを動かすと、聴衆の画面に赤い点が出る）

## アニメーション

見本には次の動きが入っています。どれも `data-steps` で順番を指定し、右矢印を押すたびに次の要素が現れます。

| 動き | 書き方 |
|---|---|
| 要素が下から現れる | `data-steps` に対象のセレクタを書く（末尾 `*` で1つずつ） |
| 流れ図の箱と矢印が順に現れる | `.flow` の中の `.step`。直前の `.arrow` も一緒に現れる |
| 棒が伸びる | `.bar` の `.bf` に `style="width:57%"` のように長さを書く |
| 数字が数えあがる | `.mv`（大きな数字）、`.bv`（棒の値） |
| 線を引いて薄くする | 語を `<span class="rd">` で囲む |

`prefers-reduced-motion` を設定した環境では、数字の数えあげを行いません。

## スライドの書き方

1枚は 1600×900 の `<section class="slide">` です。

```html
<section class="slide new" data-title="見出し" data-sec="90" data-part="本題" data-steps=".list li*">
  <div class="band">見出し</div>
  <div class="body"><ul class="list big"><li>1つ目</li><li>2つ目</li></ul></div>
  <aside class="notes">読み原稿</aside>
</section>
```

- `data-sec`：このスライドの目安の秒数。発表者の画面の「開始」時刻の計算に使います。
- `data-steps`：順に出す要素のセレクタを `|` で区切って書きます。末尾の `*` は、当てはまる要素を1つずつ出す指定です。
- `<body data-start="10:00">`：発表の開始時刻。
- URL に `?check=1` を付けて開くと、本文が枠からはみ出したスライドを調べます。`?static` を付けると、すべての要素を最初から表示します（印刷・PDF用）。

## PDF・PowerPoint にする

ブラウザで `?static` を付けて開き、印刷すると PDF になります（1600×900 のページ設定にしてください）。PowerPoint への変換は、ブラウザに表示した配置を読み取って置き直すスクリプトで行っています（このリポジトリには含みません）。

## 書体

書体は BIZ UDPGothic を Google Fonts から読み込みます。オフラインで投影するときは、BIZ UDPGothic をパソコンに入れておくと、文字の幅が変わらず、箱からはみ出しません。
